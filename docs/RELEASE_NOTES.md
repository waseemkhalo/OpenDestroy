# Destroy Dictation 0.1.0 — community preview

An independent native Mac app for voice dictation, voice notes, emoji/media selection and saved file-link insertion, with a self-hosted provider relay and personal writing settings.

Bring your own compatible provider credentials. No hosted account or provider credits are included. Saved file dictation inserts links; it does not search a cloud drive, attach arbitrary file bytes or transcribe imported media files.

This source preview is not a verified signed binary release. Real microphone/editor/provider testing, notarization and installation/update checks remain outstanding. See PARITY.md and VERIFICATION.md before using or distributing a build.
